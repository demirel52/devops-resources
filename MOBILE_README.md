# DreamSpace AI - Mobile App

Global pazarı hedefleyen Yapay Zeka İç Mimarlık uygulaması.

## Özellikler
- **AI Interior Design**: Replicate ControlNet kullanarak fotoğrafları yeniden tasarlar.
- **Before/After Slider**: Orijinal ve üretilen tasarımı karşılaştırma imkanı.
- **Luxury UI**: Dark mode, modern animasyonlar (Moti) ve NativeWind.
- **State Management**: Zustand ile hızlı ve hafif state yönetimi.

## Kurulum
1. Bağımlılıkları yükleyin: `npm install`
2. `.env` dosyasına API anahtarlarınızı ekleyin.
3. Uygulamayı başlatın: `npx expo start`

## Teknolojiler
- Expo (SDK 54)
- TypeScript
- NativeWind (Tailwind CSS)
- Zustand
- React Navigation
- Lucide Icons
